Projects

 

Regulatory Data Console

During my 2025 summer internship at Skeletal Dynamics, I replaced a ~400-spreadsheet regulatory process with one dynamic, self-maintaining system. I then rebuilt it a second time as a standalone web app to show the same architecture without Excel.

 

The problem

Skeletal Dynamics has ~20 medical systems and are planning to sell in ~20 countries. Upon my arrival, data was stored as follows: one spreadsheet per country/system combination, close to 400 files. Keeping them in sync, and re-entering data by hand from PDFs and scanned documents, was slow and error-prone heading into regulatory submissions.

solution.V1 — Excel + VBA

Consolidated the ~400 files into a single workbook, using a VBA-driven country/system selector so the workbook behaved like hundreds of purpose-built sheets while actually being one maintained file. Also wrote Python scripts and Excel formulas to automate formatting and data validation, plus a repeatable process for pasting text extracted from PDFs and Windows text-extraction tools directly into the right structured fields, instead of retyping it by hand.

View v1 on GitHub →

solution.V2 — standalone web rebuild

Rebuilt the same system as a self-contained HTML/JS app: same catalog → registration → incident structure, plus a working "paste text from a PDF, get it routed into the right field" tool driven entirely by an editable mapping table, not hardcoded per document type. Runs in any browser, no macros, and I wrote an automated test suite for it before sharing it anywhere.
